# UI/UX Guidelines

- Mobile-first layout for all customer workflows.
- Product discovery prioritizes search, category filtering and visible availability.
- Wholesale order flow prioritizes carton count, minimums and fast repeated ordering.
- Admin surfaces use dense tables and restrained controls.
- Errors should appear next to the field/action when a server action is added.
- Destructive admin actions require confirmation and audit logging.
- Toast alone is not enough for critical messages.
- Legal age and nicotine warnings must stay visible in customer journeys.
