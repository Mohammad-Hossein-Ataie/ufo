## معماری دو-تجربه‌ای پروژه

این پروژه دو محصول بصری مجزا با یک کدبیس مشترک است:

| | خرده‌فروشی (Retail) | عمده‌فروشی (B2B) |
|---|---|---|
| مسیر ریشه | `/` | `/b2b` |
| تم | تیره (Dark) | روشن (Light) |
| مخاطب | مصرف‌کننده نهایی | صاحبان فروشگاه / خریدار عمده |
| لحن بصری | مدرن، پرمیوم، ویترینی، غنی از تصویر | حرفه‌ای، تمیز، متمرکز بر داده و کارایی |
| کامپوننت‌های اصلی | `site-header.tsx`, `app-shell.tsx`, `cart-client.tsx`, `checkout-client.tsx`, `phone-login-client.tsx` | `b2b-header.tsx`, `b2b/*-client.tsx` |
| هدر ادمین | از تم B2B (روشن) پیروی می‌کند چون ابزار داخلی/کاری است | |

⚠️ قانون طلایی: هرگز توکن‌های رنگی این دو تم را با هم قاطی نکن. کامپوننتی که در هر دو بخش استفاده می‌شود باید تم را از طریق پراپ یا کلاس والد (`.theme-dark` / `.theme-light`) دریافت کند، نه هاردکد رنگ.

## توکن‌های طراحی — تم خرده‌فروشی (تیره)

```css
--retail-bg: #0E0D12;              /* پس‌زمینه اصلی، تقریباً سیاه با ته‌رنگ بنفش/سرد */
--retail-surface: #1A1820;         /* کارت‌ها و پنل‌ها */
--retail-surface-alt: #232030;     /* پس‌زمینه ثانویه، بخش‌های تفکیک‌شده، هاور */
--retail-border: #322E3D;
--retail-text-primary: #F5F3F7;
--retail-text-secondary: #A8A3B3;
--retail-accent: #E8873D;          /* نارنجی/کهربایی گرم — کنتراست با پس‌زمینه تیره برای CTA */
--retail-accent-hover: #F5975A;
--retail-success: #4ADE80;
--retail-danger: #F87171;
--retail-radius: 14px;             /* گوشه‌های گردتر = حس مدرن و پرمیوم */
--retail-shadow: 0 4px 16px rgba(0,0,0,0.35);
--retail-shadow-lg: 0 12px 32px rgba(0,0,0,0.5);
--retail-glow-accent: 0 0 24px rgba(232,135,61,0.25); /* افکت درخشش ملایم روی CTA اصلی */
```

**احساس بصری:** تیره و پرمیوم، تصاویر محصول با نور و کنتراست بالا در کانون توجه، فضای اتمسفریک (شبیه اپلیکیشن‌های سبک "premium retail" مثل استریمینگ یا فروشگاه‌های لوکس)، CTA با درخشش/glow ملایم برای جلب توجه روی زمینه تیره.

## توکن‌های طراحی — تم عمده‌فروشی/B2B (روشن)

```css
--b2b-bg: #F7F8FA;                 /* پس‌زمینه اصلی، سفید خاکستری خنثی */
--b2b-surface: #FFFFFF;            /* کارت‌ها، پنل‌ها، جدول‌ها */
--b2b-surface-alt: #EEF0F3;        /* ردیف‌های زوج جدول، هاور */
--b2b-border: #DEE1E6;
--b2b-text-primary: #14161A;
--b2b-text-secondary: #5B6068;
--b2b-accent: #2563EB;             /* آبی — اعتماد، وضوح داده، حس سازمانی */
--b2b-accent-hover: #1D4ED8;
--b2b-success: #16A34A;
--b2b-warning: #CA8A04;
--b2b-danger: #DC2626;
--b2b-radius: 8px;                 /* شعاع کوچک‌تر = حس حرفه‌ای‌تر/فشرده‌تر */
--b2b-shadow: 0 1px 3px rgba(20,22,26,0.08);
--b2b-shadow-lg: 0 8px 20px rgba(20,22,26,0.10);
```

**احساس بصری:** روشن، تمیز، بدون تزیین اضافه، فشرده و داده‌محور، کنتراست بالا برای اسکن سریع (موجودی، قیمت پله‌ای، وضعیت سفارش)، شبیه داشبوردهای B2B/SaaS حرفه‌ای.

## تایپوگرافی (مشترک بین هر دو تم)

- فونت اصلی فارسی: `Vazirmatn` (یا فونتی که هم‌اکنون در `globals.css` تنظیم شده — قبل از هرکاری چک کن)
- جهت: `dir="rtl"` روی `<html>` یا `<body>` — همه فاصله‌گذاری‌ها باید logical properties باشند (`ms-`, `me-`, `ps-`, `pe-` به‌جای `ml-`, `mr-`, `pl-`, `pr-` در Tailwind) تا در RTL خراب نشوند
- مقیاس تایپوگرافی خرده‌فروشی: عناوین بزرگ و فضادار، با کمی letter-spacing منفی روی تیترهای بزرگ برای حس پرمیوم (Hero: 40–56px)
- مقیاس تایپوگرافی B2B: فشرده و کاربردی، بدون افکت تزیینی روی تیترها (Hero: 28–36px، بدنه متن کوچک‌تر برای چگالی اطلاعات بیشتر)
- اعداد (قیمت، موجودی، شماره سفارش، پلکان قیمتی) همیشه با فونت `tabular-nums` نمایش داده شوند تا در جدول هم‌تراز باشند

## فاصله‌گذاری و گرید

- واحد پایه: `4px` (Tailwind spacing scale پیش‌فرض)
- خرده‌فروشی: فاصله‌های بزرگ بین سکشن‌ها (`py-16`/`py-24` در دسکتاپ) — حس آرام، سینمایی و ویترینی
- B2B: فاصله‌های فشرده‌تر (`py-8`/`py-12`) — اولویت با نمایش اطلاعات بیشتر در دید اول (above the fold)
- کانتینر: حداکثر عرض `1280px` برای خرده‌فروشی (تمرکز روی محتوا و تصویر)، `1440px` برای B2B (فضای بیشتر برای جدول/فیلتر/ستون‌های داده)

## کامپوننت‌ها

### دکمه‌ها
- **خرده‌فروشی:** دکمه اصلی با `--retail-accent` روی پس‌زمینه تیره، افکت glow ملایم (`--retail-glow-accent`) دور دکمه اصلی، گوشه‌های گرد (`--retail-radius`)، انیمیشن transform خفیف (`scale(1.02)`) و افزایش شدت glow روی هاور
- **B2B:** دکمه اصلی با `--b2b-accent`، گوشه‌های کمتر گرد، بدون glow یا انیمیشن اضافه — سرعت و وضوح مهم‌تر از افکت بصری است، فقط تغییر رنگ ساده روی هاور

### کارت محصول
- **خرده‌فروشی:** تصویر بزرگ در بالا با پس‌زمینه تیره اطرافش که تصویر را برجسته می‌کند، نام محصول، قیمت با فونت درشت و روشن، دکمه «افزودن به سبد» با glow
- **B2B:** ردیف جدول یا کارت فشرده روی پس‌زمینه سفید با: کد کالا، موجودی، قیمت پله‌ای (بر اساس تعداد سفارش)، دکمه «افزودن به سفارش سریع» (هماهنگ با `quick-order-client.tsx`)

### هدر (`site-header.tsx` vs `b2b-header.tsx`)
- خرده‌فروشی: لوگو (نسخه روشن/سفید لوگو برای زمینه تیره)، جستجو، سبد خرید، منوی دسته‌بندی — پس‌زمینه تیره نیمه‌شفاف با بلور روی اسکرول
- B2B: لوگو (نسخه اصلی/تیره لوگو برای زمینه روشن)، جستجوی سریع کد کالا، وضعیت حساب اعتباری/سقف خرید، دسترسی سریع به سفارش‌های قبلی — پس‌زمینه سفید ثابت با سایه ظریف روی اسکرول (نه بلور)

### فرم‌ها (لاگین، چک‌اوت)
- خرده‌فروشی (`phone-login-client.tsx`, `checkout-client.tsx`): فیلدهای ورودی روی `--retail-surface` با بوردر ظریف، مرحله‌به‌مرحله، پیام‌های خطا دوستانه و غیرتهاجمی روی زمینه تیره
- B2B (`b2b-login-client.tsx`, `b2b-checkout-client.tsx`): فرم فشرده‌تر روی زمینه سفید، امکان تکمیل سریع برای کاربران تکرارشونده (auto-fill از سفارش قبلی)، اعتبارسنجی فوری و واضح (مهم برای فرم‌های سفارش با اعداد زیاد)

## لندینگ پیج خرده‌فروشی (`src/app/page.tsx`) — تیره

ساختار پیشنهادی از بالا به پایین:
1. Hero: تصویر/ویدیوی محصول شاخص روی پس‌زمینه تیره با نورپردازی دراماتیک + پیام ارزش + CTA اصلی درخشان («مشاهده محصولات») و CTA ثانویه شفاف/outline
2. دسته‌بندی‌های محبوب (گرید کارت با تصویر بزرگ روی زمینه تیره، مرزهای ظریف بین کارت‌ها)
3. محصولات پرفروش/جدید (اسلایدر یا گرید با هاور glow روی کارت‌ها)
4. اعتمادسازی: نظرات مشتریان، ضمانت بازگشت، نماد اعتماد — روی `--retail-surface-alt` برای تفکیک بصری از پس‌زمینه اصلی
5. بنر تشویق به عضویت/خبرنامه
6. فوتر تیره با دسترسی سریع به دسته‌بندی‌ها و اطلاعات تماس

## لندینگ پیج عمده‌فروشی (`src/app/b2b/page.tsx`) — روشن

ساختار پیشنهادی از بالا به پایین:
1. Hero: پیام ارزش برای عمده‌فروش (تخفیف پلکانی، حداقل سفارش، تحویل سریع) روی پس‌زمینه سفید/روشن + CTA «ورود به پنل» یا «ثبت‌نام عمده»
2. آمار/اعداد اعتمادساز (تعداد فروشگاه همکار، حجم سفارش پردازش‌شده) در کارت‌های ساده و خوانا
3. دسترسی سریع: «سفارش سریع» (لینک به `quick-order-client.tsx`)، کاتالوگ کامل، وضعیت حساب — به‌صورت کارت‌های اکشن‌محور و فشرده
4. شرایط همکاری (پلکان قیمتی، شرایط پرداخت، حداقل سفارش) — ترجیحاً در قالب جدول ساده
5. فرم درخواست همکاری/تماس با تیم فروش
6. فوتر ساده و کاربردی (نه تزیینی)، تمرکز روی لینک‌های عملیاتی

## قوانین سراسری

- تغییر لایه UI مجاز است؛ به route ها، schema دیتابیس یا منطق API دست نزن مگر صراحتاً خواسته شود
- هر تغییر رنگی باید از توکن‌های بالا استفاده کند، نه مقدار هاردکد جدید
- قبل از هر تغییر، اگر `DESIGN_SYSTEM.md` یا `UI_UX_GUIDELINES.md` در ریشه پروژه به‌روزرسانی نشده، تغییرات را در همان فایل‌ها هم منعکس کن تا مرجع واحد بماند
- Responsive: موبایل-اول برای بخش خرده‌فروشی (اکثر ترافیک از موبایل)، دسکتاپ-اول قابل‌قبول برای بخش B2B (اکثر خریداران عمده از دسکتاپ/تبلت اداری استفاده می‌کنند) — ولی هر دو باید کاملاً ریسپانسیو باشند
- دسترسی‌پذیری: کنتراست رنگ حداقل WCAG AA در هر دو تم — به‌خصوص متن ثانویه روی پس‌زمینه تیره خرده‌فروشی باید تست کنتراست شود
- عملکرد: تصاویر با `next/image`، فونت‌ها با `next/font`، lazy load برای بخش‌های زیر fold
- لوگو و آیکون‌ها باید نسخه مناسب هر تم را داشته باشند (نسخه روشن برای زمینه تیره در بخش خرده‌فروشی، نسخه اصلی/تیره برای زمینه روشن در B2B)
